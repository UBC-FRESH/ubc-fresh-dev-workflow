The check itself is unchanged, so every personal path in a file that a commit would include is still an error. Four tests cover the cases: an ignored cache, a new untracked file, a nested directory, and a missing or failed git. `.hypothesis/` is now also ignored explicitly.

- Completed P1.4 (#21). Walk mode now reads the root `.gitignore`. Outside a repository root, the validator skips the files and directories that the file ignores, as git does, and it prunes ignored directories before it descends into them. It reads only the root file, not nested ones or `.git/info/exclude`. A line that it cannot apply is skipped, so the rule scans more files, not fewer. Those lines are a backslash, `**`, a bare slash, and a bracket that is not a valid class. A root-only self-check confirms that the repository's ignore file covers every path that the gates write. Red before the change: five end-to-end walk tests failed, because ignored files were scanned, and seven tests for the new reader failed because it did not exist yet. Green after the change: the suite passes 164 tests with 100 percent branch coverage of `scripts/`. The root dashboard was green before this commit.
- Completed P1.5 (#22). The branch-coverage gate for `scripts/` is now 95 percent, up from 90. It is set by `--cov-fail-under` in the pytest `addopts` in `pyproject.toml`, and the seed receives the same file, so generated projects get the same gate. The reason is the roadmap's ratchet. Before the change, the suite passed 164 tests with 100 percent branch coverage of `scripts/`, so a higher gate catches new untested code without any new tests. Red first: two policy tests in `tests/test_workflow.py` failed at 90. One checks the configured value, and one checks that `AGENTS.md`, `docs/reference/testing-policy.rst`, and `docs/reference/quality-gates.rst` state 95 percent and no longer state 90. Green after the change: both pass, and the full suite passes 166 tests with 100 percent branch coverage of `scripts/`, against the gate of 95. A run of one test file fails the gate at 10.60 percent, which shows that the gate is enforced. The root dashboard was green before this commit.
