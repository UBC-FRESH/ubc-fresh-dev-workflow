UBC-FRESH Dev Workflow
======================

A seed and onboarding kit for agent-assisted science and engineering projects.
It describes how UBC FRESH Lab projects plan, build, review, and release
software with coding agents, and how to set up the environment they run in.

New here? Read :doc:`guides/onboarding` first. Starting a project? Read
:doc:`guides/first-project`. An agent? Read :doc:`agents/session-protocol`
before you change anything.
